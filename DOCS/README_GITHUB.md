# GitHub-Ready Checklist & Tips

Use este checklist antes de publicar o repositório para maximizar divulgação e atração de seguidores.

1) README principal
- Tenha um `README.md` claro e com Quickstart (já criado).
- Adicione GIFs/screenshots em `public/screenshots/` e insira no README.

2) Topics & descrição
- Defina `topics` no GitHub: `react`, `vite`, `pomodoro`, `productivity`, `material-ui`.

3) Badges
- Adicione badges de Build, License (se houver), e npm version.

4) Demo
- Se possível, publique uma demo (Vercel/Netlify) e adicione link `Live Demo` no README.

5) Issues/PR templates
- Adicione `.github/ISSUE_TEMPLATE` e `PULL_REQUEST_TEMPLATE.md` para padronizar contribuições.

6) Social
- Tweet/publish a thread com as principais features, imagens e link para o repo.
