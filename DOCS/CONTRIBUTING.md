# Contributing

Obrigado por considerar contribuir com o projeto Pomodoro Pro!

Guia rápido
1. Fork o repositório
2. Crie uma branch: `git checkout -b feat/nova-funcionalidade`
3. Faça alterações pequenas e com commits descritivos
4. Rode os testes e verifique `npm run build`
5. Abra um Pull Request descrevendo claramente o que mudou

Regras de estilo
- Código: manter estilo do projeto (ESLint + Prettier). Não altere regras globais sem discussão.
- Componentes: pequenos, com responsabilidades claras.

Issues & templates
- Abra issues com cenários reproduzíveis e logs quando possível.

Como ajudar
- Reportar bugs e passos para reproduzir
- Contribuir com testes e documentação
- Sugerir melhorias de UX e performance
